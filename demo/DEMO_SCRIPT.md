# Сценарий демонстрации — День 22: Первый RAG-запрос

## Подготовка (до записи)

```bash
# Сбросить индекс — чтобы авто-индексация сработала на камеру
npm run clean:data
```

---

## Сценарий (запись)

### Шаг 1 — Показать базу знаний

Открыть `demo/knowledge.md` в редакторе. Пробежаться по файлу.

> "Это наша база знаний — выдуманная компания ПингвинТех с абсурдными фактами.
> Модель про неё ничего не знает. Сейчас это проверим."

---

### Шаг 2 — Запустить бенчмарк

```bash
npm run demo:benchmark
```

Скрипт автоматически:
1. Индексирует `knowledge.md` через Ollama (`nomic-embed-text`)
2. Прогоняет 10 вопросов один за другим
3. Для каждого вопроса выводит `[NO-RAG]` и `[RAG]` ответы со стримингом

---

### Шаг 3 — Комментировать по ходу

Пока идут вопросы, обращать внимание на контраст:

| Вопрос | NO-RAG | RAG |
|--------|--------|-----|
| Как зовут CEO? | не знает | Борис Ластоногов |
| Где офис? | не знает | Марс, Олимп-Сити, корпус 7 |
| Язык программирования? | выдумывает | Brainfuck с патчем от 2031 |
| Чем платят зарплату? | общие слова | морскими огурцами |

> "Обратите внимание на `similarity` — RAG показывает, какие именно
> фрагменты из базы были использованы для ответа."

---

### Шаг 4 — Показать таблицу контрольных вопросов

Открыть `demo/questions.md`.

> "Вот полный набор из 10 вопросов с ожидаемыми ответами и источниками."

---

## Итог (озвучить)

- **NO-RAG**: модель не знает факты из закрытой базы — отвечает уклончиво или ошибается
- **RAG**: детерминированный пайплайн `вопрос → embed → поиск → контекст → LLM` даёт точные ответы
- При первом запуске база индексируется автоматически — никаких ручных шагов
