# Сценарий демонстрации — День 34: Файловый ассистент

## Что показываем

Интерактивный агент, который сам работает с файлами: читает код,
ищет по нескольким файлам через `grep_files` / `find_files`,
анализирует и создаёт/изменяет документацию.
Задача ставится на уровне цели — агент сам решает что открывать.

---

## Подготовка (до записи)

```bash
# 1. Убедиться что сборка актуальна (новые инструменты grep_files, find_files)
npm run build

# 2. Убедиться что agent линкован глобально
which agent       # → должен показать путь

# 3. Перейти в корень проекта (там лежит .agent/)
cd ~/Documents/cli-agent

# 4. Проверить что секрет есть
cat ~/.config/agent/secrets.json | grep deepseek
```

## Сценарий 1 — Карта провайдеров (создание нового файла)

**Запустить агент:**
```bash
agent
```

**Задача:**
```
Изучи все LLM-провайдеры проекта в src/providers/ и создай файл docs/providers.md.
Документ должен содержать: список провайдеров, их конфиги (модель, URL, ключ),
и сравнительную таблицу: провайдер | требует ключ | базовый URL | когда использовать.
```

**Что увидит зритель:**

| Шаг агента | Инструмент | Что происходит |
|------------|-----------|----------------|
| Planning | — | Агент классифицирует как COMPLEX, составляет план |
| Execution 1 | `list_directory` | Смотрит что есть в `src/providers/` |
| Execution 2 | `read_file` × 3 | Читает `base.ts`, `deepseek.ts`, `lmstudio.ts` |
| Execution 3 | `grep_files` | Ищет где провайдеры используются в коде |
| Execution 4 | `write_file` | Создаёт `docs/providers.md` |
| Validation | `read_file` | Перечитывает созданный файл, проверяет |

**Тезисы по ходу:**
- "Агент сам выбрал что читать — мы не сказали открой deepseek.ts"
- "grep_files — новый инструмент, ищет паттерн по всем .ts файлам проекта"
- "Видишь planning → execution → validation — стейт-машина задачи"

## Сценарий 2 — Аудит: проверка соответствия кода и конфига

**Задача (в той же или новой сессии):**
```
Проверь соответствие: все MCP-серверы перечисленные в builtinMcpServers
в src/cli/index.ts должны иметь директорию в mcp-servers/.
Также проверь что каждый сервер из mcp-servers/ зарегистрирован в index.ts.
Выведи расхождения если есть, или подтверди что всё в порядке.
```

**Что увидит зритель:**

| Шаг агента | Инструмент | Что происходит |
|------------|-----------|----------------|
| Execution 1 | `read_file` | Читает `src/cli/index.ts`, находит builtinMcpServers |
| Execution 2 | `list_directory` | Смотрит реальные папки в `mcp-servers/` |
| Execution 3 | `grep_files` | Ищет регистрацию каждого сервера в коде |
| Done | — | Отчёт: совпадения и расхождения |

**Тезисы по ходу:**
- "Задача про аудит — агент сам формулирует что проверять"
- "Два источника истины: код и файловая система — агент сравнивает оба"
- "Результат воспроизводится: запусти снова — тот же анализ"
