# Контрольные вопросы — День 23: RAG vs RAG+Rerank

База знаний: `demo/kb/` — три компании (ПингвинТех, ОсьминогСофт, МедведДата), 5 файлов каждая.

## Почему эти вопросы

Все вопросы содержат **название компании + общий атрибут** (CEO, офис, зарплата и т.д.).
Без фильтра поиск возвращает схожие секции из всех трёх компаний — LLM получает
противоречивый контекст и путается. С фильтром (minScore ≥ 0.3) выживают только
чанки нужной компании — ответ точный.

| # | Вопрос | Ожидаемый ответ | Без фильтра | С фильтром |
|---|--------|-----------------|-------------|------------|
| 1 | Кто является CEO компании ОсьминогСофт? | Геннадий Щупальцев | 3 компании в контексте | только ОсьминогСофт |
| 2 | Где находится главный офис МедведДата? | Сибирь, Тайга-Сити, Берлога №42 | все три office.md | только МедведДата |
| 3 | Сколько сотрудников работает в ПингвинТех? | 3: два пингвина и один кальмар | все три hr.md | только ПингвинТех |
| 4 | Какой язык программирования использует ОсьминогСофт? | COBOL с телепатическим компилятором | все три tech.md | только ОсьминогСофт |
| 5 | Чем выплачивается зарплата в МедведДата? | Мёдом (senior) и малиновым вареньем (стажёры) | все три hr.md | только МедведДата |
| 6 | Как называется корпоративный напиток ПингвинТех? | Компот из антарктического криля | все три culture.md | только ПингвинТех |
| 7 | Когда была основана ОсьминогСофт? | 0 января 2042 года | все три leadership.md | только ОсьминогСофт |
| 8 | Как добраться до офиса МедведДата? | На медведях-курьерах | все три office.md | только МедведДата |
| 9 | Как называется гимн компании ОсьминогСофт? | «Восемь рук — одна душа» | все три culture.md | только ОсьминогСофт |
| 10 | Сколько длится рабочий день в ПингвинТех? | 15 минут (3:00–3:15 ночи) | все три hr.md | только ПингвинТех |

## Запуск

```bash
# Один вопрос — оба режима:
npm run demo:rag         -- "Кто является CEO компании ОсьминогСофт?"
npm run demo:rag-rerank  -- "Кто является CEO компании ОсьминогСофт?"

# Полный бенчмарк:
npm run demo:benchmark
```

## Ожидаемый контраст

| Режим | Что происходит |
|-------|----------------|
| RAG (без фильтра) | top-3 чанка из разных компаний → LLM смешивает факты или даёт неточный ответ |
| RAG+rerank (minScore ≥ 0.3) | отсекаются нерелевантные компании → LLM отвечает точно по одной компании |
